# Category C — Abstraction, Interface & Class vs Interface

Beginner-friendly Java solutions for the five Part A problems in the provided assignment.

## Programs
1. `GardenPlotAreaReport.java` — abstract base class and polymorphism for plot areas.
2. `WeeklyStaffPay.java` — abstract staff class and different pay calculations.
3. `LibraryLateFineCounter.java` — abstract library item and different fine rules.
4. `ElectricityConnectionBilling.java` — abstract connection and billing rules.
5. `TravelBooking.java` — abstract booking class with a shared booking fee.

## Compile and run
Install a Java JDK. Open a terminal in this folder and run one program at a time:

```text
javac GardenPlotAreaReport.java
java GardenPlotAreaReport
```

Use the matching filename and class name for the other programs.

## Complexity
Each program processes N input records once after reading them, so processing time is O(N). The arrays used to store the objects take O(N) space.
